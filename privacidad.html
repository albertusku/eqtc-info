Política de privacidad

Actualizada el 19 de octubre de 2026.

Esta política describe la instalación personal de eqtc y su uso de los datos obtenidos mediante las API de Google. Su responsable es la persona que administra esa instalación y figura como contacto de asistencia en la pantalla de consentimiento de Google.

Datos a los que accede eqtc

Gmail: identificadores de mensajes e hilos, remitentes, destinatarios, asuntos, fechas, etiquetas necesarias para interpretar los mensajes, fragmentos y cuerpos de texto de los correos consultados. El permiso solicitado es gmail.readonly. La integración busca y lee; no envía, borra ni modifica correos, ni descarga adjuntos.

Google Calendar: identificadores, títulos, fechas, horarios, estado y otros campos necesarios para consultar los eventos seleccionados y comprobar operaciones solicitadas por el usuario. Los permisos son calendar.events.owned para eventos de calendarios propios y, cuando se habilita la lectura de calendarios suscritos, calendar.events.readonly.

Conexión: se guardan credenciales OAuth y autorizaciones renovables para acceder a Google con los permisos concedidos. La contraseña de Google se introduce en Google, no en eqtc.

Finalidad del tratamiento

Los datos se usan para responder a consultas sobre correo y agenda, mostrar referencias a las fuentes, analizar un hilo cuando se solicita y realizar las operaciones de calendario admitidas. La creación de eventos se revisa antes de confirmar, salvo que el usuario active expresamente la creación directa a petición. El borrado requiere confirmación.

Procesamiento con el modelo local

El modelo local puede interpretar la petición del usuario. Cuando se solicita el análisis de un hilo, recibe el texto admitido de ese hilo en una operación separada para proponer una clasificación revisable. Los resultados de correo y agenda se excluyen del contexto reciente del chat general. Esta instalación no envía esos datos a servicios externos de inferencia ni los utiliza para entrenar modelos.

Almacenamiento y conservación

  • Las credenciales se guardan en archivos privados de los equipos usados para autorizar y ejecutar eqtc, fuera del repositorio de código.
  • Las consultas, respuestas y fuentes mostradas pueden guardarse en el historial local de cada navegador hasta que el usuario las borre. No se sincroniza ese historial entre navegadores.
  • Las propuestas y resultados de operaciones de calendario se conservan en una base local para gestionar confirmaciones, reintentos y operaciones inciertas. Pueden contener títulos, fechas e identificadores. No tienen un borrado automático por antigüedad en la versión actual.
  • La integración no crea una copia completa del buzón. Los datos que el usuario guarde explícitamente en otras funciones y las copias de seguridad se conservan hasta su eliminación por el usuario.

Comunicaciones y acceso

eqtc se comunica con Google para autenticar la cuenta, renovar el acceso y consultar o modificar los recursos autorizados. Los resultados se transmiten entre el servidor personal y el navegador del usuario. El acceso remoto, si se configura, utiliza la red privada de la instalación. Los datos de Google no se venden ni se utilizan para publicidad; eqtc no los comparte con servicios de análisis o modelos externos.

El uso y la transferencia de información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de API de Google, incluidos sus requisitos de Uso limitado.

Retirar el acceso y eliminar datos

El usuario puede retirar el acceso de eqtc desde las conexiones de su cuenta de Google. Si Gmail y Calendar comparten el proyecto OAuth, esa retirada puede afectar a ambas conexiones.

Para desconectar una integración localmente, se retira su archivo de credenciales de los equipos donde se haya instalado. Para eliminar resultados guardados, se borran las conversaciones o los datos del sitio en cada navegador. El responsable de la instalación debe gestionar también la base local de operaciones y las copias de seguridad, comprobando antes las operaciones pendientes. Revocar permisos no elimina automáticamente esas copias ni los mensajes o eventos originales de Google.

Esta web informativa

Los archivos de esta web no incorporan formularios, analítica, publicidad, scripts ni acceso a la cuenta de Google. La web informativa se aloja en GitHub Pages. GitHub puede tratar datos técnicos de las visitas, como la dirección IP y los registros de acceso, conforme a su declaración de privacidad.

Contacto y cambios

Para consultas sobre privacidad, utiliza el correo de asistencia indicado en la pantalla de consentimiento de eqtc. Esta política se actualizará cuando cambien las funciones o el tratamiento de datos descritos.
